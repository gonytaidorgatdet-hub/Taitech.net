## ?? Important Notes

### In-Memory Database
- All data resets when app restarts
- Great for demos, not for production
- To add persistence: Connect Postgres in Render and update server.js

### Security
- Demo credentials are hardcoded (for testing only)
- For production: move credentials to environment variables
- Add proper authentication (JWT, OAuth)
- Implement rate limiting
